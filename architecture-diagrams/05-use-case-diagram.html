UML USE CASE SensAI — Complete Use Case Model

Standard UML specification showing Primary Actor (Job Seeker), Secondary System Services, core use cases, and formal <<include>> / <<extend>> relationships

Primary Use Cases (UC1-UC10)

  • • UC1-UC3: Identity onboarding, industry insight queries, and salary radar views.
  • • UC4-UC6: 8-step resume composition, multimodal ATS scoring, and targeted cover letters.
  • • UC7-UC9: Adaptive MCQ testing, sub-second voice interviews, and DAG career progression.
  • • UC10: Clean account teardown cascading through database and file storage.

Inclusion Rules (<<include>>)

  • • Rate Limiting: Executing ATS analyses (UC-5) and Roadmaps (UC-9) unconditionally invokes Redis rate limit checks.
  • • Diagnostic Remediation: Missed quiz answers automatically trigger 2-sentence mistake isolation tips.
  • • Rubric Synthesis: Concluding a voice interview requires generating a 5-pillar evaluation rubric.

Extension Points (<<extend>>)

  • • AI Section Rewriters: Users may optionally enhance bullet points, summaries, and experience entries.
  • • Virtual A4 Print: Formatted preview nodes clone into isolated print contexts with 10.5pt font calibration.
  • • Skill Normalization: Checking off roadmap nodes prompts Gemini API to filter abstract concepts and sync verified tools to user profile.
