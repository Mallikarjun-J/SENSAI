STATE TRANSITION SensAI — UML Statechart Models

Complete technical state machine specifications for Resume Analysis, Real-Time Voice Sessions, and Progressive Skill Normalization

Resume Analysis States

  • • PENDING: Validates file upload domain and verifies document ownership.
  • • PROCESSING: Enforces 5/hr rate limit and checks SHA-256 Redis AI cache before calling Gemini API.
  • • DONE / ERROR: Persists score (0-100) or enters recoverable error state with backoff.

Voice Interview Session

  • • IN_CALL Loop: VAD speech detection, streaming STT, and streaming TTS alternate turns deterministically.
  • • Strict Policy: Agent asks exactly 5 questions and never acts as a tutor or hints at correctness.
  • • Closing Regex: Recognizing concluding remarks emits session-ended and terminates the room before scoring.

Progressive Skill Sync

  • • Milestone Completion: Checking off roadmap nodes triggers AI normalization.
  • • Filtering Fluff: Gemini API filters out abstract study concepts, isolating concrete, verifiable tools (e.g. ["Docker"]).
  • • Atomic DB Merge: Unique skills merge into User.skills in PostgreSQL and immediately sync to the Resume Builder.
