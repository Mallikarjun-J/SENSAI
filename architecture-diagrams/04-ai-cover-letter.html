Feature 4: AI Cover Letter

SensAI — Job-targeted Markdown cover letter generation via Gemini 2.5 Flash

Data Flow

  • • User enters Job Title, Company, and JD
  • • Action calls Gemini to generate Markdown
  • • Action inserts record into `CoverLetter` table
  • • Returns ID and redirects to Detail View
  • • List page fetches all history via action

AI Generation

  • • Uses primary `GEMINI_API_KEY`
  • • Model: Gemini 2.5 Flash (for speed)
  • • Prompt ensures a professional, concise tone
  • • Enforces raw Markdown output
  • • No separate schema; returns pure text `content`

UI Handling

  • • Form validation via Zod (ensures JD is provided)
  • • Loading skeleton during AI generation
  • • Renders output safely using `react-markdown`
  • • Provides "Copy to Clipboard" utility
  • • Simple one-click deletion functionality
