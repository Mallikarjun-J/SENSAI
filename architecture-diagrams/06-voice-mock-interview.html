Feature 6: Voice Mock Interview

SensAI — Redesigned to perfectly match the 3-column flow of Features 1-5.

WebRTC & LiveKit

  • • Ultra-low latency voice streaming via WebRTC.
  • • `voice-interview-form` captures setup inputs.
  • • `agent.jsx` (LiveKitRoom) connects client to SFU.
  • • SFU dispatches the room to the Python Worker.

Python Agent Pipeline

  • • **VAD:** Silero detects when the user starts/stops speaking.
  • • **STT:** Deepgram Nova-3 streams audio to text.
  • • **LLM:** GPT-4.1-mini processes text context & replies.
  • • **TTS:** Cartesia Sonic-3 voices the AI reply (Tessa).

Data Lifecycle & Failsafes

  • • `INTERVIEW_LIMIT = 7` (Checked at room creation).
  • • Agent passes JSON evaluation as a DataPacket on exit.
  • • Client receives packet and calls `saveVoiceFeedback()`.
  • • Agent runs `_delayed_end(90s)` to prevent hung rooms.
