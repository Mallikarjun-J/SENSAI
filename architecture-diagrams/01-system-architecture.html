ARCHITECTURE SensAI — End-to-End System Architecture

Complete technical architecture: Presentation Tier, Edge Gateway, Rate Limiting, Application Server, Redis Cache, Gemini API, and Database

Edge Security & Rate Limiting

  • • JWT Middleware: Intercepts protected routes at the edge via proxy.js.
  • • Rate Limiter: Enforces sliding-window burst protection (5 resume analyses/h, 3 roadmaps/h, 5 cover letters/h).
  • • SSRF Defense: Validates resume URLs strictly against trusted storage hostnames.
  • • Prompt Injection Guard: Destructures strict schema fields before database persistence.

Gemini API & Redis Caching

  • • Unified Gemini API: Orchestrates ATS scoring, resume enhancement, quizzes, roadmaps, and cover letters.
  • • SHA-256 AI Cache: Computes deterministic cache keys in ai-cache.js (24h for PDFs, 6h for text).
  • • Query Cache: Caches read-heavy lists in Redis for 5 minutes (db-cache.js) with atomic invalidation on writes.
  • • Zero-OCR Multimodal: Base64 PDF buffers stream directly into Gemini API.

Real-Time Voice Pipeline

  • • WebRTC Audio SFU: Sub-800ms bi-directional audio streaming over UDP channels.
  • • Python Agent Daemon: Dedicated worker process running agent.py.
  • • Neural VAD: Prewarmed Silero voice activity detection eliminates cold-start audio clipping.
  • • Regex Room Teardown: Detects closing sentences and cleanly tears down WebRTC rooms before rubric generation.
