UML SEQUENCE SensAI — Chronological Interaction Model

Complete technical sequence specifications across all 8 features: lifelines, activations, sync/async calls, error guards, and persistence

Edge Interception

  • • Middleware Shield: Edge middleware interrogates every request for valid session claims before executing React server components.
  • • Zero Cold-Starts: Unauthenticated requests are immediately diverted to sign-in without server rendering overhead.

Idempotent Provisioning

  • • checkUser() Action: Automatically verifies if the authenticated user exists in PostgreSQL; provisions initial record if missing.
  • • State Guard: Redirects un-onboarded candidates to /onboarding until industry parameters are seeded.

Profile Linkage

  • • Prisma Transactions: updateUser() commits industry, sub-industry, experience years, and candidate bio in a single atomic write.
  • • Cache Invalidation: Calls revalidatePath("/dashboard") to purge stale user layout caches immediately.

Dual-Layer Caching

  • • Redis AI Cache: Caches industry trends for 7 days to eliminate redundant AI calls across candidate cohorts in the same sector.
  • • Database Baseline: Serves historical fallback data immediately if network latency threatens client dashboard render times.

Structured Extraction

  • • Schema Conformity: Gemini API returns salary percentiles (entry, median, senior), demand scores, and key technologies.
  • • Atomic Upsert: Replaces expired industry rows using composite unique industry keys.

Data Flow Efficiency

  • • Sub-100ms Responses: Cache hits return in ~35ms directly from memory without invoking Gemini API.
  • • Cron-Triggered Warmup: Weekly scheduler refreshes high-traffic industries ahead of peak Monday morning application windows.

Section-by-Section AI

  • • Granular Polishers: Candidate can request AI enhancement on individual bullet points, summary paragraphs, or skill lists.
  • • STAR Standard: Formats draft duties into measurable Situation-Task-Action-Result achievements.

Layout Staging

  • • 5 Modern Templates: Supports Modern, Classic, Minimal, Creative, and Tech layouts tailored for FAANG ATS filters.
  • • Dynamic Reordering: Sections serialize into JSON arrays, allowing instant drag-and-drop hierarchy adjustments.

Single-Page A4 Precision

  • • Virtual Staging Node: Clones the preview subtree into an off-screen container with calibrated 10.5pt typography.
  • • Margin Calibration: Enforces 20mm printable boundaries to prevent multi-page accidental spillover during export.

Burst Protection

  • • Sliding-Window Guard: Restricts analyses to 5 per hour per user across uploaded PDFs and in-app builder resumes.
  • • Immediate 429: Exhausted quotas return clear reset timestamps without queuing expensive AI worker threads.

Multimodal Ingestion

  • • Zero OCR Distortion: Passes raw PDF buffers straight to Gemini API for direct native layout inspection.
  • • SSRF Defense: Validates file download origins strictly against trusted CDN hostnames before buffer extraction.

SHA-256 AI Caching

  • • Content Deduplication: Computes a deterministic SHA-256 hash over the binary buffer; cache hits return in 35ms.
  • • 24-Hour TTL: Balances cost reduction with candidate iteration speed.

Context Fusion

  • • Dual-Source Synthesis: Merges candidate resume history with target job description requirements.
  • • 400-Word Constraint: Prevents generic fluff; focuses directly on matching past achievements to role requirements.

Sliding-Window Quotas

  • • 5 Letters / Hour: Guarded by Redis rate limiting to prevent automated scraping while giving users generous draft iteration.
  • • Atomic DB Writes: Generates unique records linked directly to the candidate's account for multi-job tracking.

Markdown Editing

  • • Real-Time Markdown: Allows instant in-browser refinement, custom tone edits, and one-click clipboard copying.
  • • PDF Staging: Uses unified styling matching the candidate's active resume design template.

Dynamic Question Sets

  • • Topic Customization: Generates tailored sets of 10 to 25 questions across Technical, Conceptual, or Mixed categories.
  • • Difficulty Calibration: Tunes question complexity (Easy, Medium, Hard) to match candidate senior levels.

Server-Side Validation

  • • Tamper Prevention: Answer scoring occurs strictly on the server; client answers are evaluated against validated answer keys.
  • • Mistake Analysis: Automatically isolates incorrect choices and extracts exact knowledge gaps.

Remediation Feedback

  • • 2-Sentence AI Tips: Gemini API synthesizes targeted remediation guidance focusing on the candidate's exact weaknesses.
  • • Historical Analytics: Tracks historical score progression on the user profile to visualize topic mastery over time.

Real-Time WebRTC Loop

  • • Sub-Second Latency: Silero Voice Activity Detection (VAD) detects speaker pauses, streaming audio tokens in real time.
  • • Deterministic Flow: Python voice daemon asks exactly 5 role-specific questions sequentially without straying off topic.

Automated Teardown

  • • Regex Trigger: Detects "This concludes our interview" to trigger instant server-side room deletion.
  • • Strict Auth Validation: The /api/livekit/end-room endpoint verifies session ownership before terminating rooms.

5-Pillar Evaluation

  • • Post-Call Scoring: Gemini API evaluates full dialogue across Communication, Technical Accuracy, Problem Solving, Structure, and Confidence.
  • • Exact Dialogue Citations: Scorecard cites specific candidate quotes justifying areas for improvement.

Directed Acyclic Graphs (DAG)

  • • Prerequisite Enforcing: Structures career paths into chronological phases and milestone steps with dependency checks.
  • • Curated Video Search: Automatically links high-yield YouTube tutorial IDs for every technical topic.

Burst-Cost Mitigations

  • • 3 Roadmaps / Hour: Protects against excessive token consumption caused by multi-stage DAG generation.
  • • DB Query Caching: Roadmap progress status is cached in Redis for 5 minutes and invalidated on step checkoffs.

Automatic Skill Normalization

  • • LinkedIn-Ready Taxonomy: Filters abstract milestone names (e.g. "Intro to Cloud") into concrete skills (e.g. "AWS S3", "Docker").
  • • Profile Synchronization: Automatically appends verified skills to User.skills, immediately improving the candidate's ATS resume scores.
