UML ACTIVITY SensAI — Dynamic Workflow & Swimlanes (All Features)

Complete technical workflow partitioned into 5 architectural swimlanes across all 8 features: Client UI, Rate Limiter, Server Actions & Redis Cache, Gemini API & Cloud Services, and PostgreSQL Database

Subsystem Orchestration

  • • Unified Lifecycle: Onboarding profile feeds directly into Market Insights, Resume Builder, and AI Roadmaps.
  • • Flywheel Synergy: As users practice quizzes or master roadmaps, skills automatically sync into User Profile.

Sliding-Window Protection

  • • ATS Resumes: 5 analyses / hour sliding window via Redis counter.
  • • Cover Letters: 5 generations / hour sliding window.
  • • Roadmaps: 3 generations / hour (protecting multi-node Gemini calls).

Dual-Tier Caching

  • • AI Response Cache: SHA-256 prompt hashing caches Gemini outputs (24h for PDF analysis, 6h for letters).
  • • Query Cache: Read-heavy lists cache in Redis for 5 minutes and invalidate immediately on DB mutations.

Session Gatekeeper

  • • requireUser() verifies Clerk session token before executing any Server Action.
  • • Throws structured AuthError if unauthenticated.

Automatic DB Provisioning

  • • If User record does not exist upon sign-in, creates initial profile in single transactional insert.
  • • Avoids race conditions on concurrent logins.

State Invalidation

  • • Onboarding form update clears Redis user cache key immediately.
  • • Revalidates dashboard page route cache via revalidatePath('/dashboard').

24-Hour Redis TTL

  • • Market intelligence trends change slowly, so outputs are cached for 24 hours in Redis.
  • • Subsequent calls by any user in the same industry resolve sub-5ms with zero Gemini cost.

Database Fallback

  • • PostgreSQL stores structured historical industry trends to guarantee continuity during Redis resets.
  • • Refreshes automatically every 7 days.

Structured Gemini JSON

  • • Gemini API call generates schema-enforced JSON: minSalary, medianSalary, maxSalary, topSkills, and demandIndex.

5 Modern Templates

  • • Classic, Modern, Minimal, Executive, and the new FAANG-optimized TechTemplate.
  • • Live React DOM to PDF generation without headless Chromium overhead.

STAR AI Polishing

  • • Transforms plain statements into quantifiable STAR bullets (Situation, Task, Action, Result).
  • • Responses cached in Redis for fast re-use.

Direct In-App Analysis

  • • Resumes created in the builder can be analyzed directly via analyzeResumeFromBuilder without needing a PDF roundtrip.

Rate Limiting & SSRF

  • • Upstash sliding-window limiter blocks abuse beyond 5 requests/hour.
  • • SSRF guard strictly whitelists utfs.io, uploadthing.com, and ufs.sh hosts.

24h Binary Hash Cache

  • • Computes SHA-256 hash of PDF binary buffer. Duplicate uploads return instantly from Redis cache.

Multimodal Analysis

  • • Sends binary document directly to Gemini API for simultaneous layout and semantic ATS evaluation.

5 Letters / Hour Limit

  • • Sliding-window limiter in Redis restricts high-volume prompt spamming.
  • • Rejections return friendly HTTP 429 toast with remaining window time.

Profile Augmentation

  • • Automatically merges candidate's target skills and experiences into Gemini prompt context.

400-Word Sweet Spot

  • • Enforces concise 3-paragraph persuasive length proven to maximize recruiter engagement.

Custom Difficulty & Type

  • • Supports 10 to 25 questions, Easy/Medium/Hard tiers, and Technical/Conceptual filters.

Per-Option Explanations

  • • Every question returns thorough explanations for why each option is correct or incorrect.

Historical Progress Tracking

  • • Stores all historical attempts in Assessment table to render improvement curves over time.

Zero-Latency WebRTC

  • • Bidirectional audio stream powered by WebRTC SFU with voice activity detection (VAD).
  • • Direct conversational pipeline with sub-second turnaround.

Explicit Room Teardown

  • • End-room API validates candidate identity before deleting active room to prevent resource leaks.

6-Category Diagnostic

  • • Evaluates Technical Accuracy, Communication, Structure, Problem-Solving, Confidence, and Role Fit.

3 Roadmaps / Hour Limit

  • • Sliding-window limiter in Redis restricts high-cost multi-node DAG generations to 3/hour.

Automatic Skill Sync

  • • Marking roadmap nodes as completed invokes array_union on the User table, updating candidate profile skills in real time.

Embedded Video Discovery

  • • Each roadmap milestone automatically queries curated YouTube tutorial IDs for immediate learning.
