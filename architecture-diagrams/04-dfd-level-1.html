Central Data Stores (D1 - D9)

  • • D1 to D8 store user-scoped relational tables with foreign keys.
  • • D9 Redis provides sliding-window rate limit counters and SHA-256 AI response caching.

Skill Auto-Sync Loop

  • • When roadmaps are checked off in 8.0, mastered skills route directly back into D1 User Profiles.

Identity Ingestion

  • • Subsystem 1.0 accepts Clerk session tokens, validating claims prior to any database mutation.

D1 Relational Persistence

  • • Creates or updates the primary User table with industry preferences and biography.

Cache Invalidation

  • • User profile updates immediately invalidate user-specific Redis query caches.

24h Redis TTL

  • • Salary statistics change slowly, so Gemini outputs are stored in Redis for 24 hours.

D2 Database Archive

  • • PostgreSQL stores industry trend snapshots to provide continuity even during cache evictions.

Structured Metrics

  • • Enforces strict schema: minSalary, medianSalary, maxSalary, topSkills, and demandIndex.

5 Resume Templates

  • • Real-time staging across Classic, Modern, Minimal, Executive, and Tech formats.

D3 JSON Storage

  • • Full content structure preserved in PostgreSQL Resume table with instant re-editability.

STAR Methodology

  • • Transforms passive bullet descriptions into measurable impact statements using Gemini API.

5/hr Rate Limit

  • • Sliding-window rate limit counters in Redis protect expensive multimodal AI inference.

SSRF Protection

  • • PDF fetcher strictly verifies hosts against pre-approved storage CDNs (utfs.io, uploadthing.com, ufs.sh).

D4 Persisted Scoring

  • • ATS report persists in database to track score improvements over consecutive resume iterations.

5/hr Rate Limit

  • • Sliding-window rate limit protects token usage and prevents spam generations.

D5 Letter History

  • • All generated letters are permanently saved in PostgreSQL with full markdown formatting.

Context Fusion

  • • Fuses candidate's actual profile achievements with recruiter requirements from job post.

Custom Config Matrix

  • • Supports 10 to 25 questions, Easy/Medium/Hard tiers, and Technical/Conceptual filters.

D6 Assessment Table

  • • Persists full question metadata, chosen answers, final score percentage, and diagnostic tips.

Actionable Tips

  • • Gemini analyzes incorrect responses to deliver hyper-specific study recommendations.

WebRTC Pipeline

  • • Sub-second latency turn-taking using voice activity detection and audio streaming.

Explicit Teardown API

  • • /api/livekit/end-room verifies session ownership and terminates room to prevent orphaned charges.

D7 Rubrics

  • • Saves 6 core competencies: Accuracy, Communication, Structure, Problem-Solving, Confidence, and Role Fit.

Real-Time Skill Auto-Sync

  • • Completing a roadmap node automatically updates the candidate's User.skills array in PostgreSQL.

3 Roadmaps / Hour Limit

  • • Sliding-window limiter in Redis mitigates multi-call Gemini DAG generation costs.

Embedded Resources

  • • Attaches curated YouTube tutorial IDs and documentation links to each node for immediate learning.
