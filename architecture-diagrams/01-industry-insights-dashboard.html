Feature 1: Industry Insights Dashboard

SensAI — AI-generated market analytics with 7-day caching

Data Flow

  • • page.jsx fetches via Promise.all()
  • • getIndustryInsights() checks DB cache
  • • Cache miss → Gemini generates JSON
  • • Result saved with 7-day TTL
  • • getUserProfile() fetches user data

AI Prompt Output

  • • salaryRanges (5+ roles with min/max/median)
  • • growthRate (percentage)
  • • demandLevel (High / Medium / Low)
  • • marketOutlook (Positive / Neutral / Negative)
  • • topSkills, keyTrends, recommendedSkills

UI Components

  • • Recharts BarChart (salary ranges in K)
  • • Radix Progress bar (demand level)
  • • Badge components (skills, trends)
  • • EditProfileModal (experience, bio, skills)
  • • date-fns "Last updated" formatting
