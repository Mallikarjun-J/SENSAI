DFD LEVEL 0 SensAI — System Context Data Flow Diagram

Standard textbook DFD notation: Yellow Rounded Rectangles (External Entities), Blue Circle (Central Process 0.0), and zero-collision data flow badges

System Boundary (0.0)

  • • Central Execution: Process 0.0 encapsulates all Next.js React Server Components, server actions, and edge middleware.
  • • Decoupled Actors: Candidate traffic and AI background daemon processes communicate strictly through structured boundaries.

External Entities (Yellow Rectangles)

  • • Identity & Auth: External Auth Service verifies session claims and emits JWT payloads.
  • • Gemini API: Provides shared multimodal scoring, STAR re-writing, and question generation.
  • • Voice Cloud: Coordinates WebRTC audio transport with prewarmed sub-second agent daemons.

Data Flows & Buffers

  • • Raw PDF Buffers: Securely stream from trusted CDN origins into Process 0.0 memory for zero-OCR inspection.
  • • Dual Storage Sync: Structured data commits transactionally to PostgreSQL while transient rate counters sit in Redis.
