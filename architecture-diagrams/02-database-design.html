Relational Integrity & Cascades

  • • Central Identity: User table roots all user-owned assets via foreign keys.
  • • Cascade Deletion: Deleting a candidate user cleanly purges linked Resume, Interview, VoiceFeedback, Roadmap, and ResumeAnalysis rows.
  • • Account Wipe Action: In actions/user.js, user deletion systematically cleans storage CDN files before database cascade execution.

JSONB Structured Payloads

  • • Builder Flexibility: Resume sections (skills, experience, projects) serialize directly into PostgreSQL JSONB trees.
  • • DAG Canvas State: Roadmap retains coordinates and checked states in JSONB without over-normalizing node rows.
  • • 5-Pillar Voice Rubric: Detailed rubric comments, citations, and scores persist natively in VoiceFeedback.categoryScores.

Indexes & Cache Invalidation

  • • Targeted B-Tree Indexes: Foreign keys feature @@index([userId]) to accelerate tenant-scoped queries.
  • • Unique Slugs: IndustryInsight.industry uses a unique constraint for atomic upserting.
  • • Dual-Layer Invalidation: Mutations in Server Actions automatically invoke invalidateCache() to purge stale Redis query lists.
