Feature 3: Resume Analyzer

SensAI — Upload PDF → ATS scoring across 5 categories with actionable tips

Execution Flow

  • • Check `RESUME_ANALYSIS_LIMIT` (5 per user)
  • • PDF is uploaded and parsed to raw text
  • • DB record created with `PENDING` status
  • • Gemini analyzes text asynchronously
  • • DB updated with `COMPLETED` and JSON results

AI Prompt Details

  • • Uses isolated `RESUME_ANALYSIS_KEY`
  • • Model evaluates across 5 specific ATS categories
  • • Forces output to structured JSON schema
  • • Generates an overall 0-100 `score`
  • • Returns specific, contextual `actionableTips`

UI & Visualization

  • • Progress/loading indicators during AI lag
  • • Circular SVG Score indicator component
  • • Tabbed interface for the 5 categories
  • • Expandable cards for actionable tips
  • • Persists history (users can see past analyses)
