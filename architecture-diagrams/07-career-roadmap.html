Feature 7: Career Roadmap

SensAI — Redesigned to perfectly match the 3-column flow of Features 1-5.

Data Flow & Parsing

  • • Unlike the Quiz, this action does NOT use a JSON schema.
  • • It relies on a custom regex `parsePhasesFromResponse()` to extract `Phase/Day X:` blocks from raw markdown.
  • • Action cleans markdown artifacts before sending the parsed array to the React client.

AI & Limits

  • • Uses a completely isolated environment variable: `ROADMAP_API`.
  • • Strictly enforces `ROADMAP_LIMIT = 2`. Users can only ever generate two roadmaps in their account lifetime unless upgraded.

UI Delivery

  • • Server action returns a clean JS array of phase objects.
  • • React Client maps these into a visual timeline component.
  • • No complex state management needed compared to the quiz; it's a read-only visualizer once generated.
